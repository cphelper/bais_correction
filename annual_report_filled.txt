23. Report of the Work done:

   i) Objectives
   - Quantify uncertainties in CMIP6 Significant Wave Height (SWH) and Sea Level Anomaly (SLA) over 2015–2023 against satellite altimetry.
   - Develop AI/ML models to correct CMIP6 biases (pilot Random Forest; planned QRNN/DeepAR/BNN with uncertainty).
   - Generate probabilistic long-term forecasts for the Indian Ocean and extend the framework globally.
   - Validate using spatial/temporal cross-validation, tide-gauge checks, and extreme-event cases.
   - Deliver corrected datasets (NetCDF) with uncertainty layers on MOSDAC for user agencies.

   ii) Summary of the work done
   - Project setup and onboarding completed; data access and storage pipeline established.
   - Acquired and organized CMIP6 and satellite altimetry datasets for SWH and SLA.
   - Implemented preprocessing + QC + co-location and regridding pipeline (Python/xarray), enabling monthly aligned analyses.
   - Completed pilot SWH analysis for the Indian Ocean (2015–2020) and developed a Random Forest correction model.
   - Initiated SLA preprocessing and baseline trend estimation at global scale; pilot automation demonstrated.
   - Prepared scripts/plots and reproducible artifacts (trained model + figures) for reporting and publication workflows.

   Annexure A: Proposal summary (≤200 words; from initial proposal)
   Sea level anomaly and significant wave height play a vital role in coastal management and planning.
   Projections of these variables under Shared Socioeconomic Pathways (SSPs) are available from CMIP6
   based on simulations from multiple Earth System Models (ESMs) up to 2100. ESMs suffer from
   inherent errors due to imperfect parameterizations and incomplete understanding of interactions and
   feedback mechanisms; consequently, projections of critical parameters may contain significant biases
   that can misguide climate adaptation planning. This project quantifies uncertainties in CMIP6 sea level
   anomaly and significant wave height using satellite altimeter observations for the observed period
   (2015–2022/2023) and develops state-of-the-art data analytics / AI-ML models to learn differences
   between observations and simulations. The learned correction models will then be applied to future
   CMIP6 projections to produce corrected products and associated uncertainty information for decision
   makers and user agencies.

   Annexure B: Linkages to Space Programme / Deliverables to ISRO
   - Satellite data utilization for societal benefits:
     - Use SLA and SWH observations from SARAL/AltiKa and other international missions; EOS-04 SAR
       derived wave height is also planned for use where applicable.
   - Deliverables:
     - Bias-corrected CMIP6 SLA and SWH projections (NetCDF) and uncertainty layers for multiple SSPs.
     - Dissemination through MOSDAC web portal with documentation/metadata.
     - Inputs to ISRO for sensor/observing-system gap analysis and future mission requirements.

   Annexure C: Approach (as per proposal; condensed)
   - Data processing (~8 months): acquire CMIP6 variables (SWH, zos/SLA) for multiple models/SSPs;
     acquire merged altimeter products (e.g., AVISO/DUACS) for SLA/SWH; QC, aggregation, unit
     conversions; compute SLA anomalies vs long-term means; align/regrid; split 2015–2021 train and
     2021–2023 validation (proposal plan; implemented split may vary by pilot dataset availability).
   - Uncertainty modelling (~13 months): QRNN, DeepAR, BNN, ensemble methods, transformer-based
     models, and deep Gaussian processes; compare using coverage probability, interval length, and
     training time; select models per resource constraints.
   - Model evaluation (~7 months): evaluate CMIP6 model skill for SLA/SWH and define metrics aligned
     with prediction-interval performance.
   - Recomputing projections (~8 months): apply learned bias/uncertainty models to generate corrected
     long-term projections.
